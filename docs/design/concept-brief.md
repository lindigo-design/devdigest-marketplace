# Catalog site: concept brief (Lindigo, Phase 1)

**Thesis.** A plugin catalog is reference material, so it should read like a well-set technical index: the query is the headline and everything else stays quiet so you can choose and copy in under a minute.

**Audience & purpose.** Developers and course participants who arrive with a task ("I need a skill for security review"), scan, check what a plugin is allowed to run, and copy one install command back into their terminal.

**Aesthetic direction.** Editorial / Swiss: an asymmetric grid, oversized serif display and generous whitespace. Monospace is the second voice, used only for commands, paths and versions, because code is content here.

**Emotional tone.** Precise, calm, trustworthy.

**The one memorable thing.** The search line is set as display type: "I need a ___" in oversized serif, with results running beneath it like the entries of a printed index.

**Anti-goals.**
- Not an app store: no grid of identical glossy tiles.
- No SaaS gradients or glass.
- Stats are numerals, not charts.
- No emoji type icons.
- No Inter.
- Not a dark-only hacker terminal.
